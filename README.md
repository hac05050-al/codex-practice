## イベントページのプレビュー方法

ローカル環境で `index.html` を確認するには、以下のいずれかの方法を利用してください。

1. ブラウザで直接開く
   - ファイルマネージャーから `index.html` をダブルクリックするか、ブラウザで `index.html` を開きます。

2. 簡易サーバーを起動する
   - ターミナルでリポジトリ直下に移動し、次のコマンドを実行します。
     ```bash
     python3 -m http.server 8000
     ```
   - ブラウザで `http://localhost:8000/index.html` にアクセスすると、ページをプレビューできます。

スマートフォンや他の端末から確認したい場合も、同じネットワーク内のIPアドレスに置き換えればアクセスできます。
